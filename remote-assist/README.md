# سند — مساعدة عن بُعد

نسخة أولية مستقلة لمشاركة الشاشة ونقل الملفات بين متصفحين عبر WebRTC. لا تعتمد على كود TeamViewer ولا تتجاوز ترخيصه.

## التشغيل

- التطوير: `npm run dev` ثم افتح `/remote-assist/` على عنوان Vite المحلي.
- نسخة الإنتاج: `npm run build` ثم `npm start`.
- تطبيق سطح المكتب للمضيف: `npm run desktop`؛ يبني الواجهة ويشغل التطبيق وخادم الإشارات محليًا.
- خادم التطوير وخادم الإنتاج الافتراضيان يستمعان محليًا على الجهاز فقط.
- نشر الموقع وخدمة الإشارات على Cloudflare Workers: اتبع التعليمات في `README.md` داخل مجلد المشروع.

## بدء جلسة

1. المضيف يختار «ابدأ مشاركة الشاشة» ويوافق على نافذة النظام.
   - في المتصفح، اختر الشاشة كاملة بدل تبويب المتصفح لتجنب شريط «مشاركة التبويب». هذا مؤشر أمان من المتصفح ولا يمكن للصفحة إخفاؤه. تطبيق سطح المكتب يشارك الشاشة الرئيسية دون شريط تبويب المتصفح.
2. يرسل رمز الجلسة للطرف الآخر عبر قناة موثوقة.
3. الطرف الآخر يفتح التطبيق ويدخل الرمز؛ يتفاوض التطبيق تلقائيًا على اتصال WebRTC.
4. بعد الاتصال يمكن للطرفين إرسال ملف حتى 100 ميغابايت.
5. لطلب التحكم، يختار الطرف المشاهد الفأرة أو لوحة المفاتيح أو كليهما. يظهر على جهاز المضيف مربع نظام مستقل يختار منه الصلاحيات المسموح بها؛ يمكن للمضيف سحبها فورًا من زر «إيقاف التحكم».

## حدود وأمان النسخة

- خادم الإشارات مضمّن في Vite أثناء التطوير، وفي `server.mjs` للتشغيل الذاتي، أو Durable Objects عند النشر على Cloudflare. الجلسات مؤقتة وتنتهي بعد 45 دقيقة.
- الخادم يحد عدد الجلسات النشطة إلى 500 وعدد الجلسات الجديدة لكل عنوان شبكة إلى 20 في الدقيقة.
- رمز الجلسة سرّ حامل: أي شخص يملكه يستطيع محاولة الانضمام. أرسله لشخص تثق به فقط. معرّف الجهاز وكلمة المرور الثابتان مخصصان لتطبيق سطح المكتب، ولا يغنيان عن موافقة صاحب الجهاز على مشاركة الشاشة والتحكم.
- الخادم ينسق تبادل SDP مؤقتًا؛ الفيديو والملفات تنتقل عبر WebRTC. التطبيق لا يوفّر حاليًا خادم TURN، لذلك قد تفشل شبكات تمنع الاتصال المباشر.
- مشاركة شاشة المضيف متاحة فقط على المتصفحات والأنظمة التي تدعم Screen Capture API. خارج `localhost` يجب تقديم التطبيق عبر HTTPS.
- الهاتف يقدر ينضم ويشاهد عبر متصفح متوافق؛ مشاركة شاشة الهاتف تعتمد على دعم النظام والمتصفح.
- التحكم بالنظام يتطلب تشغيل تطبيق سطح المكتب على جهاز المضيف؛ المتصفح وحده لا يرسل إدخالًا إلى نظام التشغيل. المضيف يوافق محليًا على نطاق كل طلب، وتُسحب الصلاحية عند إنهاء الجلسة أو إغلاق التطبيق.
- إعدادات الشاشة تشمل جودة بث تقريبية، ومعدل الإطارات، وملاءمة الشاشة أو ملئها أو عرضها بحجمها الأصلي، ونافذة فيديو عائمة أو ملء الشاشة، والمظهر الداكن. تطبيق الجودة والنافذة العائمة يعتمد على ما يسمح به المتصفح ونظام التشغيل.
- التحكم متاح على Windows وmacOS وLinux X11 عبر مشغل إدخال النظام. قد يحتاج macOS إلى إذن Accessibility من إعدادات النظام؛ Linux Wayland غير مدعوم حاليًا. الأجهزة المحمولة يمكنها المشاهدة والانضمام عبر متصفح متوافق، لكنها لا تعمل كمضيف للتحكم بالنظام.
- تطبيق سطح المكتب يمكن تشغيله من المصدر عبر `npm run desktop`، أو تثبيت نسخة Windows x64.
- مُثبّت Windows x64: `npm run desktop:installer` ثم شغّل `release/Sanad-Setup-0.1.0.exe`. ضع أصل خادم HTTPS المشترك في إعدادات سطح المكتب، واجعل الطرف الآخر يستخدم نفس الموقع.
- لا يضم المشروع اشتراك TeamViewer ولا يتصل بخدماته. Cloudflare يقدم حصة مجانية محدودة وقد تتوقف الطلبات بعد تجاوز حدودها؛ تفاصيلها تتغير حسب الخطة. خادم TURN غير مضمّن، لذلك قد تحتاج بعض الشبكات إلى خدمة إضافية.
