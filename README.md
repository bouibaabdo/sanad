# سند للمساعدة عن بُعد

تطبيق مستقل لمشاركة الشاشة والمساعدة عن بُعد عبر WebRTC، مع تطبيق سطح مكتب للتحكم بالنظام بعد موافقة صاحب الجهاز. لا يحتوي على كود TeamViewer ولا يتجاوز ترخيصه.

## التطوير محليًا

يتطلب Node.js 20.19+ أو 22.12+.

```sh
npm ci
npm run dev
```

افتح `/remote-assist/`. لبناء الواجهة وتشغيل خدمة الإشارات محليًا:

```sh
npm run build
npm start
```

لبناء تطبيق سطح المكتب أو مثبّت Windows x64:

```sh
npm run desktop
npm run desktop:installer
```

## النشر على Cloudflare من GitHub

ملف `wrangler.jsonc` يربط ملفات الواجهة بخدمة Worker، ويستخدم Durable Object مع تخزين SQLite لإشارات WebRTC ومعرّفات الأجهزة. لا يحتاج المشروع إلى خادم Node دائم أو قاعدة بيانات خارجية.

1. ارفع هذا المستودع إلى GitHub.
2. في لوحة Cloudflare افتح **Workers & Pages** ثم أنشئ Worker من **Workers Builds** واربطه بمستودع GitHub.
3. اترك مجلد المشروع الجذر `/`، واجعل أمر البناء `npm run build` وأمر النشر `npx wrangler deploy`.
4. اربط نطاقًا من إعدادات Worker، ثم افتح `https://your-domain/remote-assist/`.

بعد أول نشر، يجهّز Wrangler Durable Object من نوع SQLite. تطبيق سطح المكتب يستخدم نطاق الموقع نفسه تلقائيًا بعد وضعه في الإعدادات تحت «خادم الاتصال».

الواجهة تبدأ بالفرنسية، ويمكن تغييرها إلى الإنجليزية أو العربية من «Paramètres». عند نشر إصدار Desktop جديد، ينشر GitHub Actions ملف التثبيت أولًا، ثم يشغّل نشر Worker عند نشر الإصدار. أضف أسرار المستودع `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID` لتفعيل النشر الآلي إلى Cloudflare.

Cloudflare Workers/Durable Objects متاحة بخطة مجانية ضمن حصص يومية محددة؛ إذا تجاوز الاستخدام الحصة المجانية تتوقف العمليات الزائدة في الخطة المجانية. اطلع على [الأسعار والحدود الحالية](https://developers.cloudflare.com/durable-objects/platform/pricing/) قبل تشغيله لمستخدمين كثيرين.

## ميزات وسلامة الاتصال

- كل نسخة سطح مكتب تنشئ معرّف جهاز ثابتًا وكلمة مرور عشوائية محفوظة محليًا بتشفير النظام.
- يجب تشغيل مشاركة الشاشة على الجهاز المضيف؛ تظهر موافقة النظام قبل بث الشاشة. طلبات الفأرة ولوحة المفاتيح تعرض موافقة منفصلة ويمكن سحبها.
- عند النشر على Cloudflare تُخزّن كلمة المرور كتجزئة PBKDF2، وفي الخادم المحلي كتجزئة scrypt. محاولات الاتصال محدودة، والاتصال النشط مؤقت وينتهي عند إيقاف المشاركة.
- الفيديو والملفات تنتقل عبر WebRTC بين الجهازين. خدمة الإشارات تنقل عرض الاتصال والرد فقط؛ قد تحتاج الشبكات المقيدة إلى خادم TURN غير مضمّن.
- جلسة الرمز العشوائي تنتهي بعد 45 دقيقة. الأجهزة والاتصالات بكلمة المرور الثابتة لا تكون متاحة إلا أثناء تشغيل مشاركة الشاشة.
- متصفح الهاتف يمكنه الانضمام للمشاهدة أو إرسال الملفات. التحكم بنظام التشغيل يحتاج تطبيق سطح المكتب على الجهاز المضيف.

المشروع مستقل ولا يوفر ميزات TeamViewer المدفوعة أو خوادمه. يتيح Cloudflare استضافة مجانية ضمن حدود خطته، ولا يعني ذلك اتصالًا غير محدود أو ضمان عمل WebRTC عبر كل الشبكات.
